# Bundled Pi model catalog

Extracted from `@earendil-works/pi-ai@0.87.1` on 2026-09-28. [pi-models-source.json](pi-models-source.json) records the fixed npm archive, archive SHA-256, upstream commit and original catalog generation time. The JSON preserves every provider/API/model record from `dist/providers/data/*.json`, including currently unconsumed upstream fields, with two-space indentation and a trailing newline. It is data only and requires no Pi runtime. Updates are explicit reviewed changes; builds never fetch model data.

This release contains 41 provider catalogs and 1495 models, including Meta and Radius. Radius static records are retained as source data, but selectable Radius routes still come from the selected gateway and credential-scoped account catalog, or explicit configuration. A public snapshot is not proof of account access. The npm archive omits license text; `PI-LICENSE` comes from upstream commit `f07218c4d4bbc12bef056a7058c3dd49dfe41abe`, whose MIT license covers the data.

The selected remote catalog overlays this baseline by provider and model identity. For pi.dev, only cache data with a Last-Modified later than the bundled generation time overlays it; legacy caches without that timestamp are revalidated. Custom sources remain deliberate overrides independent of Pi's release clock. Remote-only removed models disappear on a successful refresh; bundled models absent remotely remain fallback entries. See [model catalog behavior](../../../docs/models.md#configuration-and-trust).
